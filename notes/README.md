## 分期说明

- **前800年**是本项目选择的叙事起点，并非文明突然开始的年份；必要时会回溯Mycenaean civilization——迈锡尼文明与Late Bronze Age collapse——晚期青铜时代崩溃。
- **前323年**是Alexander去世和Hellenistic Age——希腊化时代传统起点，是明确的时代分界。
- **前201年**是Second Punic War结束、Rome称霸西地中海并即将全面介入Eastern Mediterranean的战略分界。它不是希腊化时代的终点，但适合作为Rome崛起叙事的阶段界线。
- 第三个时期的最终截止点尚不预设。应由后续历史内容决定，而不是为了让各目录长度整齐而强行切割。
