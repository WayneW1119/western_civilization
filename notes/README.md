## 分期说明

- **前800年**是本项目选择的叙事起点，并非文明突然开始；必要处会回溯Mycenaean civilization与Late Bronze Age collapse。
- **前323年**是Alexander去世与Hellenistic Age的传统起点。
- **前201年**是Second Punic War结束、Rome称霸西地中海并即将全面介入Eastern Mediterranean的战略节点。
- **前44年**以Caesar遇刺为界：旧Republic的问题并未解决，继承战争最终产生Principate。
- **公元235年**以Alexander Severus被杀为界：Severan秩序结束，皇位、边疆、财政和疾病危机开始连锁化。
- **公元410年**不是Roman Empire终结，而是Western协调能力变化的象征节点；Eastern Empire仍将以Constantinople为中心继续发展。
